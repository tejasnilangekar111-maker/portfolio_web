# Tejas Nilangekar — Portfolio

Personal portfolio website of **Tejas Nilangekar**, Java Backend Developer at TransUnion.

🔗 **Live site:** https://tejasnilangekar111-maker.github.io/portfolio_web/

## About

I'm a Java Backend Developer with 2.5+ years at TransUnion, building and supporting high-throughput
financial data systems with Spring Boot. I specialise in CIBIL parameter configuration, database
optimisation and production support for credit-scoring systems.

This site showcases my:

- **Experience:** Associate Developer and Intern at TransUnion
- **Technical skills:** Java, Spring Boot 3, Spring Data JPA, REST APIs, Microservices, PostgreSQL, MySQL, React.js
- **Projects:** BNPL (Buy Now, Pay Later) system with a credit-scoring engine, EMI calculator and Spring Batch jobs
- **Education:** B.Tech in Electronics and Telecommunication, VIT Pune (CGPA 8.38)

## Features

- Responsive design for desktop, tablet and mobile
- Dark and light themes, with the choice remembered
- Animated sections that appear on scroll, and stats that count up
- Glass-style cards with a glow that follows the mouse
- Downloadable résumé (PDF)

## Built with

- HTML5
- CSS3 (custom properties, grid, flexbox and animations)
- JavaScript (no frameworks or build step)
- Hosted on GitHub Pages

## Run locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/tejasnilangekar111-maker/portfolio_web.git
```
